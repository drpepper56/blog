Google Data Analytics Capstone Project

wip

A walkthrough and rationale of steps taken in completing the capstone project for Google Data Analytics Certification on Coursera. Data was cleaned and transformed using R dplyr, visualisations were made using Tableau. Full transformation script, data source and a more numerical documentation is available at the end of this article.

The dataset used for this project is from a urban bike renting company from Chicago, it only includes records of trips taken and the attributes do not hold any user information. Loading the huge data set from separate csv files to one data frame in R was done using a recursive function that took a list of files and returned the data frame.

Cleaning and Transformation

Missing values were found in columns that describe the start and end station name and ID number, station longitude and latitude.

The coordinate values had various number of significant figures after the decimal point, considering this, to make it easier to work on the each individual, they were split into latitude and longitude fields. Records with missing names or IDs of stations were given the values of records with only very close coordinate matches. The same was done in reverse, giving coordinate values to fields with matching name and ID of a station. Coordinate values slightly varied in groups of matching station name and ID so the coordinate values were served based on the mode from the group.

Data Inconsistencies were found in the names and ID values of stations. Mismatched name and value pairs

All names were trimmed of spaces, prefixed and suffixes in names like “Temp” or “Public Rack” where removed if the same ID was found without the extra text. In some cases the names prefixed with “Public Rack” had the same IDs but a different group of coordinate values, making their difference valid, the IDs from that group were prefixed with PR to preserve that data. After that there were 8 inconsistencies left, some had unique suffixes that were removed, random numbers were replaced with matching ID names and the “true” inconsistencies left were fixed by adding a D prefix to the ID value of the group with less entries.

ID inconsistencies were easily fixed after the previous step by assigning the majority ID value to the whole group.

The combined field was split into separate time and date field to make it easier to work on. Records that had missing time or date or start time recorded chronological after the end date, were removed. A field for trip duration was added

Where the coordinates were accurate enough a distance field was added, otherwise it was set to NA. Records with distance zero and both start and end station set and different to each other were removed.

Added a field to hold the average speed of the trip by dividing the trip distance by the trip time.
